## 5. البنية التقنية (كما هي الآن)
- **Stack:** TypeScript + React 19 + Vite + zod 4 + Dexie (IndexedDB) + ts-fsrs 5 · PWA (manifest + sw) · الاختبار: vitest + renderToStaticMarkup + fake-indexeddb.
- **المسارات:** `src/lib/` (المحركات: brand, first-run, unit0, routes, state-factory, audio, asr-gate, **lesson-engine E01, coach-engine E02, day-engine E06, review-engine E03, errors-engine E04, audio-engine E05, dictation-engine E07, warmth-engine E08 — M1 مكتملة** + **lesson-runner — مُشغِّل الدرس** + **advanced-listening E09, pronunciation E10, reading E11, writing E12 — M2-أ مكتملة**) · `src/components/` (FirstRun, GenderBadge, **LessonSession + LessonContent — الحصة تعمل**) · `src/lesson-packs.ts` (حزم المحتوى) · `src/stores/db.ts` (Dexie) · `content/` (schemas zod + words [15 كلمة A1] + lessons + unit0 + manifests [17 مساراً صوتياً]) · `tools/` (gen-audio.py, audio_probe.py, pcm_compare.py, asr_test.py, validate-content.ts) · `tests/` (25 ملفاً).
- **الصوت:** Piper محلي (CC0) — 24kHz OGG/Opus، RMS −17dB (−20..−14)، مقطع الكلمة ≤1.5s.
- **أوامر:** `npm i` (بعد كل جلسة جديدة!) → `npx vitest run` → `npx tsc --noEmit` → `npx tsx tools/validate-content.ts` → `npx vite build`.
