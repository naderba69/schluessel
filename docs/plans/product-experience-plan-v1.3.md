## 2. الشاشات التي سترها وتستعملها (كتالوج كامل)

│  ─ مولر يرحب بك ويشرح لك بجملتين:    │
│  «لن نختبرك أبداً. نحن نبدأ من        │
│  الصفر الحقيقي، والاسترجاع هو السر» │
│            [ لنبدأ ]                  │
└──────────────────────────────────────┘
   ↓
┌──────────────────────────────────────┐
│  ما اسمك؟                            │
│  [ اكتب اسمك هنا          ]          │
│            [ أنا جاهز ]              │
└──────────────────────────────────────┘
   ↓
┌──────────────────────────────────────┐
│  الوحدة صفر — 4 بطاقات قصيرة         │
│  (لماذا الاسترجاع؟ لماذا النوم        │

ثم تصل إلى شاشة «اليوم» — ورحلتك بدأت فعلاً.

### 2.2 الشاشة الرئيسية — «اليوم» (تفتحها كل يوم)
```
┌──────────────────────────────────────┐
│  مرحباً يوسف · اليوم: الاثنين        │
│ ┌──────────────────────────────────┐ │
│ │  هدف اليوم (من خطتك):            │ │
│ │  «يُعرّف بنفسه في جملتين…»       │ │
│ └──────────────────────────────────┘ │
│  ●●●○○○○  أسبوعك (3/7)               │
│                                      │
│  [ ▶ ابدأ جلسة اليوم (120 دقيقة) ]   │
│                                      │
│  · مراجعات مستحقة اليوم: 12 بطاقة    │
│  · أخطاؤك الذهبية: 2                 │
│  · مقفل حتى فتحه: 🔒 الوحدة 2        │
└──────────────────────────────────────┘
```
- **«هدف اليوم»** مأخوذ حرفاً من الخطة اليومية v6.1.
- زر واحد كبير: **ابدأ الجلسة**. لا قوائم متشعبة ترهقك.

### 2.3 شاشة الجلسة — قلب التجربة (**حصة واحدة متصلة من 120 دقيقة** — مثبت بطلبك)
كل حصة = أربع محطات داخل الحصة الواحدة (استراحات قصيرة بينها فقط — لا تقسيم للحصة نفسها):
```
المحطة 1 — استرجاع قصير (≈15 د)
   مراجعات الأمس/الأسبوع (SRS) · جولة سريعة على أخطائك الذهبية
المحطة 2 — الجديد (≈40 د)
   كلمات/جمل جديدة بأسلوب مولر: ألمانية + معنى + صورة/ترميز مزدوج + صوت
   (سؤال أولاً ثم شرح — دائماً)
المحطة 3 — التدريب (≈50 د)
   تطبيق: بناء جمل، اختيار، استماع، تحدث قصير — مع خلط مقصود (interleaving)
المحطة 4 — الخلاصة (≈15 د)
   ماذا تعلمت اليوم · تقييم ذاتي · مولر يجدول مراجعاتك (FSRS) · رسالة قصيرة منه
```
- شريط تقدم بأربع نقاط فوق كل محطة — تعرف أين أنت دائماً.
- استراحة مقترحة بعد كل محطة (التطبيق يذكّرك بلطف — بلا ضغط).

### 2.4 شاشة الكلمة/البطاقة (المادة التعليمية)
```
┌──────────────────────────────────────┐
│  ● die Wohnung          🔊 (صوت)     │   ← الجنس: لون + شكل + حرف (لا يُنسى)
│  الشقة                                  │
│  [ صورة/رمز بصري مزدوج ]               │
│  «Meine Wohnung ist klein.» + معناها   │
│  ⚠ مصيدة شائعة: ~~Wohnungen~~ ×        │
│     الجمع: Wohnungen (قاعدة -ung→-en)  │
└──────────────────────────────────────┘
```
- كل كلمة: صوت + صورة + جنسها باللون والشكل (der ▲ أزرق / die ● أحمر / das ■ أخضر).
- المصائد الشائعة **عند مدخل الكلمة** (وقاية لا علاج).

### 2.5 شاشة الاسترجاع (SRS) — «التكرار المتباعد»
```
┌──────────────────────────────────────┐
│  كم عدد سكان…؟   أولاً: حاول تذكر!    │
│  [ أظهر الإجابة ]                      │
│  ↓                                     │
│  الإجابة + شرح قصير من مولر           │
│  كم كانت صعبة؟  [ نسيت | صعب | جيد |  │
│                   سهل ]                │
└──────────────────────────────────────┘
```
- تدوس تُظهر الإجابة ثم تقيّم — والتطبيق يحسب موعد المراجعة القادمة (FSRS) بدل عنك.
- **لا تُسأل عن جديد قبل أن تسترجع القديم أبداً.**

### 2.6 شاشة الاستماع والنطق — «السلم السمعي» (بصراحة مثبتة)
- تصغي للكلمة/الجملة (صوت محلي)، تردد، تقارن نطقك بنطق مثالي.
- **الحكم الآلي على نطقك = إرشاد فقط** (اختبار D16 أثبت أن الحكم الآلي غير صالح كحكم نهائي — البديل مُفعَّل: الاستماع أولاً والمقارنة الذاتية، ومراجعة مولر عند الحاجة). لا نعدك بما لا نستطيع ضمانه.

### 2.7 دفتر «الأخطاء الذهبية»
- كل خطأ أخطأت فيه يُسجَّل تلقائياً في دفترك، ولكل خطأ: **لماذا أخطأه الناطق بالعربية تحديداً** + تمرين تصحيحي.
- جولة سريعة على هذه الأخطاء في بداية كل جلسة (المحطة 1) — أخطاؤك هي كنزك.

### 2.8 شاشة «الخريطة» (تقدمك)
```
A1 ▓▓▓▓░░░░ A2 ░░░░ B1 ░░░░ B2 🎯
  الوحدة 1: ●●○○  |  اليوم 3/62 أسبوعاً
  [+ بوابة كل 6 أسابيع (اختبار مفصلي — ليس تموضع)]
```
- رؤية هادئة لتقدمك (D23): لا أرقاماً مخيفة، لا «خسرت سلسلتك!» — فقط أين أنت وخطوتك التالية.

### 2.9 الإعدادات (خفيفة)
اسمك · نوافذ المدرب · الألوان · نسخة احتياطية/استعادة (بضغطة) · مسح البيانات · عن المشروع. لا حسابات ولا تعقيد.

### 2.10 «المدرب» — حضور طول اليوم خارج الحصة (جديد — كل الأفكار مقبولة)
**الفكرة:** إلى جانب حصة الدرس، مولر يمتد ليكون **مدرّبك الشخصي المتاح طول اليوم**: يدرّبك ويطوّر مهاراتك في اللحظات الصغيرة خارج الحصة.

| # | الفكرة | الوصف |
|---|---|---|
| 1 | زر «درّبني» | مهمّة واحدة 60–120 ثانية في أي وقت (استرجاع/جملة/استماع) |
| 2 | نوافذ المدرب | 2–4 أوقات تختارها (افتراضياً 3: ظهيرة، عصر، مساء) — ينبض بلطف، تقبل أو تؤجل بلا لوم |
| 3 | عبارة اليوم | جملة ألمانية كل صباح: تسمع وتردّد |
| 4 | محادثة الدقيقة | مولر يخاطبك صوتياً وأنت ترد — حوار مصغر |
| 5 | التكرار الحرفي (Shadowing) | تردّد على مولر، تسجّل صوتك، تقارن بنفسك |
| 6 | وضع الطريق | تدريب صوتي بلا شاشة (مشي/سيارة — أمان) |
| 7 | مهارة اليوم | مهارة مصغّرة معلنة كل يوم (أرقام، ch/sch…) |
| 8 | الخطأ الذهبي العابر | تمرين واحد لخطئك المتكرر في نافذتك |
| 9 | التحدي الأسبوعي | مهمة مهارية الجمعة/السبت (سجّل تقديماً 30 ثانية…) |
| 10 | إغلاق اليوم | قبل النوم: «ماذا تتذكر من اليوم؟» (تثبيت + النوم شريكك) |
| 11 | تقرير المدرب المسائي | سطر واحد هادئ بلا أرقام مخيفة |
| 12 | معاينة الغد | جملة واحدة عما سيأتي غداً |

**حارس المدرب (مبادئ لا تُكسر):** خارج الحصة = **تثبيت ومهارات فقط** — لا محتوى جديد أبداً · كل تفاعل 30 ثانية–3 دقائق · مجموع اليوم ≤ 20 دقيقة اختيارية · **الأحد وضع الراحة** · مجاني بلا إنترنت · بلا لوم وبلا سلاسل ضغط (D23).

### 2.11 أول استخدام — طقس البداية (جديد بقرار المالك 2026-10-09)
أول مرة يفتح المستخدم التطبيق:
1. **شاشة ترحيب واحدة** هادئة (بلا حسابات ولا بريد).
2. **«ما اسمك؟»** — خانة إدخال يدوي واحدة. **الاسم يُحفظ محلياً ويثبت طوال الرحلة** (IndexedDB + نسخة احتياطية)، ويظهر في: التحية اليومية، تقارير المدرب، إغلاق اليوم («تصبح على خير يا …»). قابل للتعديل من الإعدادات في أي وقت.
3. **اختيار اسم للرحلة** (اختياري): اسم المشروع الذي سيظهر في أعلى الشاشة طوال الرحلة — يُحفظ معها.
4. **ضبط نوافذ المدرب** (2–4 أوقات) — يمكن تأجيلها لاحقاً.
5. ثم **اليوم الأول** يبدأ مباشرة (الوحدة صفر).
> **لا اسم مفروض:** «رحلة يوسف» مرفوض كاسم منتج بقرار المالك؛ يبقى اسماً تقنياً داخلياً للمستودع فقط ولا يظهر للمستخدم أبداً.

### 2.12 ركن الفيديو + المحادثة الذكية (جديد بطلب المالك 2026-10-09)
- **ركن الفيديو:** رف مصنف حسب مستواك من مصادر مجانية موثقة (Nicos Weg/DW، Dreaming German، Easy German، Jojo sucht das Glück، Marija…) + **فيديو اليوم** (3–6 دقائق يقترحها المدرب) + سؤال تثبيت بعده. الفيديو يتطلب إنترنت — نقولها صراحة؛ والبديل بلا إنترنت = قصص Piper الصوتية. كل رابط يمر ببوابة التحقق (§34) قبل إضافته.
- **المحادثة خارج الدرس بالذكاء الاصطناعي — ثلاث طبقات صادقة:** (1) **مولر النصي** — أشجار حوار من مفرداتك، تعمل بلا إنترنت، مضمونة 100%؛ (2) **محادثة صوتية حية** — تعرف كلام المتصفح + صوت Piper، مجانية، استشارية (درس D16) والكتابة بديل دائماً؛ (3) **شريك AI حقيقي** — اختياري تماماً، تربطه **بمفتاحك المجاني** (مثل Gemini free tier) — صفر تكلفة علينا وعليك، والنظام يعمل 100% بدونه. حراس ثابتون: تثبيت ومهارات فقط، AI مقيّد بمستواك، تصحيح يدخل دفتر الأخطاء، شفافية أي طبقة تعمل.
- التفاصيل الكاملة: `video-and-ai-conversation.md` (F241–F262 + E23–E24).

## 9. أسئلة قد تخطر لك (بإجاباتها المتفق عليها)
- **هل سيكون هناك اختبار تحديد مستوى؟** لا — أبداً، بأي شكل.
- **هل هو مجاني؟** نعم — بالكامل وعلى جهازك.
- **أين بياناتي؟** على جهازك أنت، مع نسخة احتياطية تستعاد بضغطة.
- **ماذا لو غبت يوماً؟** لا لوم ولا «خسرت تقدمك» — نكمل من حيث توقفت.
- **هل يحكم التطبيق على نطقي؟** إرشاداً فقط — الحكم المعتمد الاستماع والمقارنة ومراجعة مولر (نتيجة اختبار موثقة).
