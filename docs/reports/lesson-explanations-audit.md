# تدقيق شروحات الدروس — هل هي كاملة وتتبع منهجية احترافية؟ (2026-10-14 — D114)

> **سؤال المالك:** «هل شروحات الدروس كاملة وتتبع بيداغوجية ومنهجية احترافية؟»
> **الجواب الصادق: لا — التصميم والمحركات احترافية، لكن محتوى الشرح نفسه ناقص في معظمه.** القياس على 79 درساً (61 محتوى + 18 توليف) عند c87906b، ومقابل ما يَعِد به مخطط الدرس وما تطلبه خطتنا (study-plan v6.1 §4).

## 2. ما هو احترافي فعلاً (يُبنى عليه)
- **البنية:** استرجاع ← جديد بمحاولة قبل الكشف (F121) ← تطبيق مخلوط ← خلاصة + SRS — حصة 120 دقيقة متصلة (D29).
- **بطاقات التحذير:** 3 في كل درس (79/79) — تحليل تقابلي خاص بالعربي (خريطة التداخل 10‑ي) بالخطأ الشائع ← لماذا يقع فيه العربي ← الصحيح + تمرين. **أقوى عنصر في المحتوى.**
- **أهداف سلوكية + Can-do يومي** · **مهمة تواصلية بمعايير نجاح** (CLT) · **الخلط من اليوم الثالث 36/36** · اختبار قبلي (pretesting) · منزلق المعايرة (ما وراء المعرفة) · SRS · صوت لكل كلمة (791 مقطعاً).
- **تصميم محرك القواعد E13** اكتشاف موجَّه حقيقي: أمثلة أولاً ← سؤال استنتاج ← القاعدة ← مقارنة عربية إلزامية ← ترتيب «حبّات الجملة». ينقصه المحتوى لا التصميم.

## 3. خطة الإصلاح (D114): «مرور ترقية» لكل درس — مرة واحدة، بالترتيب، وحدة وحدة
كل درس محتوى يُعاد فتحه **مرة واحدة** ويخرج كاملاً (ودمجه مع نواة D113 يمنع فتح الدرس مرتين):
1. **قاعدة اليوم** بصيغة الاكتشاف الموجَّه (≥3 أمثلة من كلمات الدرس ← سؤال استنتاج ← القاعدة بالألمانية والعربية ← مقارنة بالعربية ← ترتيب جملة + بنود تطبيق بتصحيح تفسيري) — ملف خزانة حقيقي بالمعرّف المُشار إليه، يعرضه المُشغِّل في محطة «الجديد» بعد الكلمات.
2. **التطبيق:** ≥ 12 بنداً في ≥ 3 أنواع محطات (منها الاستماع بالصوت الموجود والإملاء) — **كل بند بشرح «لماذا»**.
3. **كلمات النواة (D113)** المسندة للدرس: مدخل كلمة كامل (IPA · صوت · بطاقات) + دمجها في العرض والتطبيق + `status: done`.
4. **إصلاحات النص** المستحقة في الدرس + فحص قانون الجبهة لنصوصه.
5. **Quiz** ≥ 6 بنود للنسخة.
- **حارس مثل D113:** خطة ترقية (pending/done لكل عنصر في كل درس) يفرضها المدقِّق — «done» يُتحقق منه آلياً (القاعدة موجودة وصالحة · عدد البنود وشروحها · …) و«pending» دَين معلن لا يختفي بصمت.
- **ما لا يُبنى الآن:** الصور (خط الصور §15 لاحقاً) · جمل القصة (قرار: تُكتب أو يُحذف الحقل بتغيير معلن — عند ترقية الوحدة 1).
- **الحجم بصدق:** 61 درس محتوى — نحو دفعة لكل درس بجودة حقيقية. البداية: الوحدة 1، والدرس الأول نموذجاً مرجعياً.
